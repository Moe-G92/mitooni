Localize, apply logical direction and at least 44px target, with source motion/reduced-motion behavior reviewed. The source utility is useful; copying it unchanged would contradict Persian-first acceptance.
3. **Separate real auth construction from preview.** Actual `lib/supabase.ts` constructs its client at module evaluation. AuthContext imports it and passwordReset imports it again; AppBootstrap and Theme also import real profile API. A JSX condition around a synthetic provider is insufficient if these modules are statically imported. Use separate entry/composition modules and/or explicit injected transport/provider interfaces so preview can preserve provider semantics without loading real client/service code. Production missing configuration fails closed. A client role string or preview URL/query/localStorage value must never confer server authority.
4. **Resolve the dependency/lock wording.** Manifest says derive a narrow receiving manifest/lock; shell plan permits source-compatible package/lock preservation. Use source-compatible versions for the admitted closure, reviewed scripts and a receiving lock. A lockfile is dependency metadata rather than learner content, but no wholesale source script installation or speculative upgrades are authorized by calling it reproducibility. Include `@tailwindcss/postcss` when the ported PostCSS configuration imports it. Every added dependency must correspond to an admitted import/tool.
5. **Keep transport semantics, adapt its hazards.** Spot-checked `lib/api.ts:327–504`: source already forwards a Bearer token, has `expectedUserId`, preserves a provided idempotency key over its one 401 refresh retry, handles 204/invalid JSON and carries source checkout fields. Remove checkout coupling. `apiIdempotentPost` creates a UUID per helper invocation; it does not establish one operation across a user retry/reload. Preserve caller-owned IDs for future writes. Do not broaden retries to arbitrary writes. Source backend `read_retry_transport.py` deliberately retries only eligible bodyless REST GET, excluding RPC; keep that restraint.
6. **No source entrypoint or implicit source authority.** Actual backend main loads parent `.env.local`, imports all business routers and starts revision/CV/welcome lifespans. No unmatched copied file, symlink, source-relative import, Git metadata, env, data dump or output directory. For unchanged D rows, hashes match; for A rows, retain a reviewable diff. Hash only admitted files, never scan protected corpus/learner directories to create fingerprints.
- **Graph closure:** build roots are production `main` and independent preview `main`, plus their CSS and public/worker entrypoints. Reject outside-root resolution and runtime imports into the source checkout. Review emitted bundle modules/assets and public files, not only TypeScript imports. - **Configuration/egress:** no source `envDir`, parent env loader, parent filesystem allowlist, prerender alias, source proxy/default origin, source project identifier, production URL or tracking registration. Assert zero third-party/source-provider attempts, even aborted ones. Test fresh storage and reload; source consent/intent/theme/recovery keys are neither read nor written.
- **Preview exclusion:** production dependency graph/public inventory contains no preview entry/provider, synthetic sign-in grant or fixture dataset. Build production without configuration: protected route shows configuration/auth-unavailable state rather than synthetic learner. Attempt `?preview=1`, source and target storage flags, direct protected URLs and invalid routes: none grants access. - **Provider behavior:** in preview/test composition, cover loading→signed out; signed in→bootstrap failure→retry; signed out after account switch; stale profile response arriving after a different account; theme load/save rejection; toast dismissal; unavailable route/chunk recovery and bounded reload.
