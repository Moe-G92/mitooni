## Smallest robust first path

A synthetic actor with explicit review assignment opens a real source-grounded speaking activity, captures or selects a synthetic PCM WAV, previews playback, submits once and receives durable qualitative feedback or an explicit unavailable/insufficient-audio state. This is a recorded rehearsal, not a full interactive examiner test.

Submission freezes attempt ID, task ID/version/hash, activity/family/pack version, assessment ID/version/hash, exposure/conditions snapshot, recording ID/SHA256/size/type/duration/sample metadata, transcript revision if any and job dispatch identity. Hash comparisons occur before dispatch and before persistence/replay. A changed task, assessment or recording cannot silently reuse old feedback. Versioned archived results remain reviewable under current authority with their source/version limitations. Published/approved learner activity graph receives references only through coordinator-owned review gates; this adapter does not publish content or create band claims.

Admission proposal: narrowly support uncompressed PCM WAV, mono or stereo, 16-bit, 8–48 kHz, 0.25–180 seconds, maximum 18 MiB (engineering limits, not IELTS rules). Inspect RIFF/WAVE structure and decoded frames; compare actual size/duration to declared bounds, reject inconsistent/truncated formats and unknown chunks only if the decoder cannot safely identify complete audio. Hash exact admitted bytes. No caller-provided filesystem path or remote URL. Browser WebM/M4A must be decoded locally into this accepted format by a separately reviewed bounded transcoder or remain unsupported with a clear recovery action; never relabel a browser blob WAV. Silent synthetic tones can verify admission/wiring only, not speaking quality. Synthetic speech fixtures are needed for later audio-validity review.

Private media storage is outside public assets, same-origin authorization checked on every fetch including byte ranges, no public/signed long-lived recording URL, no browser provider key. Only the explicitly authorized actor/workspace/attempt and assigned reviewer may access recording or feedback. Current role/assignment revocation also blocks idempotent replay. A media reference is not authority. No real learner upload leaves this Mac during foundation work.

State flow: admitted private blob → frozen submitted attempt + unique queued job in one repository transaction → fenced claim → durable dispatch marker → one bounded provider request → strict candidate validation → completion stored with request/response binding and usage. Same idempotency key + same frozen body replays; changed body conflicts. Preparation performs no IO. Timeout, crash, canceled transport or lost lease after dispatch becomes `dispatch_unknown`, never automatic paid retry. Before-dispatch failures can be retried safely under the same transaction policy. Explicit model/budget/provider enablement is required; unavailable configuration causes no request. Unknown state requires an authorized reconciliation/new-dispatch decision.

Feedback schema: exactly one record for each `fluency-coherence`, `lexical-resource`, `grammatical-range-accuracy`, `pronunciation`; qualitative observation, actionable revision, evidence list `{recordingSha256,startSeconds,endSeconds,observation}`, or `insufficient_evidence` with a bounded reason. All intervals finite, ordered, within immutable duration, tied to admitted hash, and not transcript offsets. Transcript is optional auxiliary content with uncertainty; it may help lexical/grammar feedback but cannot replace the waveform. Pronunciation and auditory-fluency judgments require audio evidence or abstention. Model-selected timestamps remain unverified estimates until a human listens; mark this limitation first-class. No numeric band field, official equivalence, CEFR conversion or overall score in this first schema. Return limits/uncertainties per feedback and preserve source/assessment version privately.
