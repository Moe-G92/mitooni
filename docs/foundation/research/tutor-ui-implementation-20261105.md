## State/recovery

- Work and draft revision are server-owned. Dirty editor state is separate; a pending mutation locks submitted fields. Save performs CAS and obtains canonical structural state before submit/send. Lost-save retry retains the exact operation key/body; explicit discard is required to replace local dirty text on conflict.
- Submit freezes the current attempt. Supported revision creates a child attempt/draft; prior messages/quotes remain attributed to earlier saved work, not the new editor. Raw Reading check renders only the matching frozen attempt and raw counts, never a band.
- Tutor sends save acknowledged work first; feedback uses an owned frozen attempt. Only one active turn is offered; generation stays status-only until canonical committed messages appear. Polling uses bounded no-cursor snapshots. latestTurnId supports recovering lost POST ACK, including a failed terminal turn, without automatically re-POSTing generation. Uncertain dispatch blocks a fresh send pending canonical recovery.
- All work requests inherit the current subject/epoch. Every async completion also checks mounted scope; route trees are keyed by account epoch/workspace. Revoked/not-found work purges loaded task/draft/tutor state and latches the closed scope rather than allowing an older success to restore it.
- Independent work has no tutor controls until explicit user confirmation and successful server help switch, except server-permitted post-submit review. Model text cannot supply consent, links, roles, conditions or progression. Typed server proposals alone create next-step controls; acceptance returns to server journey choices.
- Generated text, observations, quotes and citation labels are inert React text. Approved anchor details come only from the owned permitted workspace; unknown historical references remain labels. Current-work quotes are checked by codepoint offsets; historical quotes are server-validated frozen snapshots and clearly labeled earlier work. No semantic-entailment or perfect prose-safety claim.
- Mobile Task/Tutor views stay mounted behind accessible pressed-state controls. Explicit exit/internal links warn before discarding dirty work; reload uses the browser unsaved-work guard. Unsaved keystrokes are not claimed durable, and browser history/session loss are not an offline-draft service.
