## Proposed contract

VisualSpec schemaVersion1; id; kind (table, line_chart, bar_chart, process, map); title; factualAlt; sourceRefs; sourceBindings (sourceRefId,fileSha256,excerptSha256,pdfPages); contentBindings (contentId,relativePath,jsonPointer,canonicalValueSha256); verification (source_verified or provisional, notes); payload discriminated by kind. Raw alt lists values/stages without teacher overview, ranking claims, inferred causes or model-answer prose. Separate teacher explanation remains existing assessment-only content.

Tables: ordered columns with key/label/type; rows with stable IDs and exact cells; measure and unit. Charts: category/time dimension with labels; ordered series with labels and numeric values; explicit axis label/unit/domain/ticks; exact year status recorded/projected; legend; source footnotes limited to factual units/limitations. Do not transform table to chart silently. Each value anchored by the parent normalized payload hash; observed-data declarations carry exact source page/figure anchor. Reject unanchored/nonfinite values unless explicitly provisional (never ready for serving).

Processes: stable nodes with stage number, action, materialBefore/materialAfter, equipment/inputs/removals; explicit edges with relation next/material_input/material_removed; no inferred edges. Validate unique node IDs, dangling endpoints, cycles in next sequence, ordered stage coverage and each edge source anchor. A source that depicts a simple sequence has no conditional branch unless branch condition and outcomes are explicit in evidence. Maps require views/dated labels, geometry and explicit coordinate provenance; never synthesize unsupported floor plans.

AssetManifest schemaVersion1; rendererVersion; assets entries id,kind,mediaType,relativePath,sha256,byteLength,width,height,specPath,specSha256,sourceRefs,contentBindings,verification. Sidecar editable JSON is an authored spec, not a source page. Rendition SVG/PNG hash and spec hash make generated derivatives immutable. Path resolver rejects traversal, symlinks outside owned root, wrong suffix/MIME, missing files, hash drift and duplicate IDs. SourceRefs resolve canonical source-index only. CorpusEntityIds remain optional until actual private database resolution; never derive IDs from guessed source paths/revisions.

Private corpus graph integration supplied by ingestion owner: corpus_aliases.relative_path→corpus_assets.active revision→corpus_pages.page_number→corpus_entities. Entity IDs hash revision-bound region IDs and must be read from actual review/corpus-20261106/store.sqlite3. Proposed media graph links: activity→uses_visual→authored visual; visual→derived_from→actual page/figure entity; visual→has_rendition→PNG/SVG. Missing full-corpus entity lookup is explicit pending lineage, never fabricated graph completeness.
