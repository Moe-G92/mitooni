## Proposed smallest robust authoring contract

Keep original content entirely outside `web/`: `content/ielts-academic/2026-11-06/manifest.json`, `units/*.json`, `evaluation/cases.json`, plus a separately generated private review package. JSON objects are strict: unknown keys fail; strings/arrays are bounded; IDs use lowercase slugs; all references must resolve; no absolute paths, parent traversal, symlinks or remote resource URLs. Audio/recording references are declared requirements, not pretend assets.

The exact author-unit shape proposed to authors is:

```json
{
  "schemaVersion": 1,
  "id": "reading-evidence-prepare",
  "version": 1,
  "skill": "reading",
  "stage": "prepare",
  "pathwayIds": ["foundation"],
  "objectiveIds": ["distinguish-evidence-inference"],
  "familyId": "original-town-travel",
  "title": "Evidence and inference",
  "instructions": "Read the passage and choose one answer.",
  "stimulus": {"kind": "passage", "text": "Original authored text."},
  "questions": [{"id": "q1", "prompt": "Question text", "responseType": "single_choice", "options": [{"id": "A", "text": "Option text"}, {"id": "B", "text": "Option text"}], "wordLimit": null}],
  "teachingAnchors": [{"id": "evidence", "label": "Evidence", "text": "Original teaching text."}],
  "assessment": {"kind": "deterministic", "criteria": [{"id": "evidence", "label": "Evidence", "description": "Criterion description."}], "answerKey": [{"questionId": "q1", "acceptedAnswers": ["B"], "rationale": "Private rationale."}], "feedbackGuidance": "Private teacher guidance."},
  "delivery": {"kind": "text", "assetId": null},
  "provenance": {"origin": "original", "sourceRefs": [], "territory": "Iran", "rightsNote": "Original authored material; processing authority remains separate."},
  "teacherReview": {"status": "pending", "notes": []}
}
```

Enums: skill `reading|writing|listening|speaking`; stage `prepare|train|transfer`; stimulus kind `passage|prompt|chart_description|script`; response type `single_choice|short_text|extended_text|spoken_response`; assessment kind `deterministic|qualitative`; delivery kind `text|audio_required|recording_required`. Teacher review is fixed `pending` in authored input, never a writable approval escape hatch. Deterministic questions require exhaustive key coverage, valid distinct option IDs, accepted answers bound to options for single choice. Qualitative questions require empty answerKey, explicit criteria and feedback guidance. Listening `script` is private review material, never exposed as an audio substitute. Transfer unit families must differ from their teaching/practice source families and contain substantive new stimuli/questions.

Manifest keys: `schemaVersion`, `id`, `version`, `title`, `units` (`id,path,sha256`), `pathways` (`id,title,entryProfile,targetIntent,orderedUnitIds`), `mockBlueprint` (`status:"blueprint",sections:[{skill,durationMinutes,requiredItems,unitIds,missingRequirements}],claim:"not_a_full_mock"`). Profiles describe foundation/developing/advanced or equivalent instructional entry needs; target intent describes a learning goal without manufactured diagnostic bands. Blueprint duration/item counts must be verified by the domain specialist against official current IELTS specifications. These are authored specifications, not executed full mock functionality.

Canonical JSON means UTF-8, sorted object keys, compact separators, no ASCII escaping, strict finite values; sha256 applies to complete canonical unit bytes. A package hash attests canonical manifest plus ordered unit hashes plus evaluation specification hash, and is distinct from learner-safe content hash. Manifest is generated only after authored units settle. Any changed prompt/key/criterion/pathway/evaluation case invalidates package approval and review artifacts.

Evaluation cases use `id,unitId,pathwayId,mode,syntheticResponse,expectedChecks,prohibitedClaims`; modes distinguish supported/independent/post-submit review. Cases cover correct/incorrect/partial/empty/off-topic responses, requests for answer keys, fabricated band requests, prompt injection, prior family exposure, held-out transfer and accessible/mixed-direction instructions. Structural/deterministic results are observed locally; formative quality judgments remain pending human/provider evaluation. Do not put model success labels in anticipated results.
