**Preferred: staged allowlisted platform port, preserving substantial original implementation and adapting its seams.** Port the actual shell/providers/primitives/transitions, auth/BFF infrastructure and useful feature modules, in verified slices. An explicit source path/hash/adaptation manifest records copied code, approved asset provenance and exclusions. Each slice expands the admitted graph. Alternative “complete safe source port” is viable as a receiving source-code inventory only if every admitted file, embedded prompt/fixture, asset and build hook is classified before copying. It must still replace startup/router registries and source configuration before anything can run. Blind tree-copy then cleanup risks moving protected content and executing workers first; reject that ordering. A full sanitized code snapshot could be retained outside the runtime graph if it materially reduces later extraction work, but is optional and requires the same admission scan. Git history, repository metadata, datasets, cache/storage directories, SQL dumps, vector IDs, local state and credentials never accompany it.

Alternative “minimal shell strip” means aggressively deleting provider/behavior dependencies until a static sidebar compiles. It is small in lines but loses source auth, loading, theme, motion and error semantics and creates work to rebuild them. Reject that as the target architecture. A bounded internal fixture adapter is appropriate to make the real shell runnable before live services; it must preserve interfaces and be impossible to ship as authenticated production behavior.
